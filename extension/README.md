# Recapper — расширение для браузера (MVP)

Лёгкий помощник для встреч, которые идут **в браузере**: Google Meet, Яндекс Телемост (веб),
Zoom (веб-клиент), Контур.Толк (веб), Microsoft Teams (веб). Расширение записывает звук
**вкладки встречи** (что говорят собеседники) и **ваш микрофон**, отправляет их на сервер Recapper
(тот же, что у веб-интерфейса и десктоп-приложения) и показывает результаты в **боковой панели**
браузера:

- ваши голосовые задачи («Ассистент, допиши механику монетизации игры: конверсия покупки из
  приложения Самоката в Купер») и ответы ассистента на них;
- вопросы и задачи, прозвучавшие на встрече, — ответ по кнопке «Ответить»;
- быстрые действия (Live Assist): «Догнать: что было за последнюю минуту», «Итог на текущий
  момент», «Что спросить дальше», «Поручения на текущий момент», «Темы встречи»;
- поле «Спросить ассистента»;
- «Завершить встречу» → итог и ссылка на полный отчёт в веб-интерфейсе сервера.

Работает в Chrome, Microsoft Edge и Яндекс Браузере (Chromium, Manifest V3) на Windows и macOS.
Нужна версия браузера на основе Chromium 116 или новее.

## Установка

### Из папки (режим разработчика)

1. Откройте страницу расширений:
   - Chrome — `chrome://extensions`
   - Edge — `edge://extensions`
   - Яндекс Браузер — `browser://extensions` (список дополнений — «Настройки → Дополнения»,
     но загрузка распакованного расширения доступна на странице `browser://extensions`).
2. Включите **«Режим разработчика»** (переключатель справа вверху; в Edge — слева внизу).
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `extension/`
   (ту, где лежит `manifest.json`).
4. Закрепите значок Recapper на панели браузера (значок-пазл → «булавка»), чтобы он был всегда
   под рукой.

### Из архива `recapper-extension-<версия>.zip`

Архив собирается командой `node scripts/pack.mjs` и появляется в `extension/dist/`.

- **Сам zip-файл браузер не устанавливает**: если перетащить `.zip` на страницу расширений,
  ничего не произойдёт (перетаскиванием ставятся только `.crx` из магазина). Поэтому
  **сначала распакуйте архив** в постоянную папку (не во «Временные файлы» — браузер будет
  загружать расширение оттуда при каждом запуске), а затем:
  - либо «Загрузить распакованное расширение» → выберите распакованную папку;
  - либо **перетащите распакованную папку** на страницу `chrome://extensions` при включённом
    режиме разработчика.
- Тот же zip подходит для загрузки в Chrome Web Store / Edge Add-ons (в нём нет тестов и
  служебных файлов, в `manifest.json` нет поля `key`).

После обновления файлов нажмите «Обновить» (круглая стрелка) на карточке расширения.

## Подключение к серверу

Расширение само ничего не распознаёт и не «думает» — это делает сервер Recapper.

1. Нажмите значок Recapper → откроется боковая панель. При первом запуске раздел
   **«Подключение к серверу»** уже открыт (потом — кнопка с ползунками справа вверху).
2. **Адрес сервера**:
   - приложение Recapper на этом компьютере (десктоп-приложение или `python -m recapper serve`):
     `http://127.0.0.1:8000` (или порт, который показывает приложение);
   - сервер в интернете/в компании: только `https://…`. При сохранении браузер спросит
     разрешение на доступ к этому адресу — разрешите, иначе расширение не сможет к нему
     обращаться. Незашифрованный `http://` разрешён только для `127.0.0.1` и `localhost`.
3. **Токен доступа** — параметр `?token=…` из ссылки, которую печатает сервер
   (`RECAPPER_URL http://127.0.0.1:8000/?token=…`), или токен из настроек приложения.
   Токен хранится только в этом браузере (`chrome.storage.local`).
4. **«Сохранить»**, затем **«Проверить подключение»** — появится строка вида
   «Подключено: Recapper 0.1.0 · ИИ: claude · распознавание речи: faster-whisper».
   Если распознавание речи на сервере выключено, панель предупредит: без него звук не
   обрабатывается (включите его в настройках Recapper).

Язык интерфейса расширения (русский/английский) берётся из настройки сервера «Язык интерфейса».

## Как пользоваться

1. Откройте вкладку со встречей и **нажмите значок Recapper именно на ней** — так браузер
   разрешает расширению записать звук этой вкладки (разрешение `activeTab`). Боковая панель
   откроется справа.
2. Выберите открытую встречу на сервере («Подключиться») или создайте новую — название по
   умолчанию берётся из заголовка вкладки.
3. Поставьте галочку **«Участники знают о записи»** (без неё запись не начнётся), оставьте
   нужные источники: «Звук вкладки встречи» и/или «Мой микрофон», нажмите **«Начать запись»**.
   Звук вкладки продолжает звучать у вас в колонках/наушниках.
4. Скажите вслух «Ассистент, …» — задача и ответ появятся в разделе «Мои задачи ассистенту»
   (обычно через 10–20 секунд: звук отправляется фрагментами, их длина задаётся на сервере,
   по умолчанию 12 с; тишина не отправляется).
5. «Завершить встречу» → запись останавливается (последний фрагмент досылается), сервер
   собирает итог → в панели появится итог и кнопка **«Открыть отчёт»**.

Боковую панель можно закрыть — запись продолжится (значок покажет «REC»); при повторном
открытии панель подхватит текущую встречу.

### Разрешение на микрофон (один раз)

Невидимая страница, которая записывает звук, не может сама показать запрос разрешения.
Поэтому в настройках панели есть кнопка **«Разрешить микрофон»**: она открывает вкладку
расширения, где вы нажимаете кнопку и разрешаете доступ в запросе браузера. Если браузер
предлагает варианты, выберите постоянное разрешение (например, «при каждом посещении»),
а не «только в этот раз».

Если микрофон запрещён или не найден, запись продолжится только со звуком вкладки
(и наоборот: если звук вкладки недоступен — только с микрофоном); панель покажет причину.
Снять запрет: `chrome://settings/content/microphone` → расширение Recapper → «Разрешить».

## Какие разрешения запрашивает расширение и зачем

| Разрешение | Зачем |
|---|---|
| `sidePanel` | показывать интерфейс в боковой панели браузера |
| `tabCapture` | записывать звук вкладки со встречей (только после вашего нажатия «Начать запись») |
| `activeTab` | право работать с вкладкой, на которой вы нажали значок Recapper (нужно для `tabCapture`) |
| `offscreen` | невидимая страница расширения, которая держит запись и отправляет звук, даже когда панель закрыта |
| `storage` | хранить адрес сервера, токен и выбранную встречу в этом браузере |
| `http://127.0.0.1/*`, `http://localhost/*` | обращаться к приложению Recapper на этом компьютере |
| `https://*/*` (необязательное) | запрашивается только если вы укажете удалённый https-сервер, и только для его домена |

Расширение не читает содержимое страниц, не собирает статистику и отправляет звук только на
указанный вами сервер Recapper. Сервер удаляет аудиофрагмент сразу после распознавания.

## Ограничения MVP

- Только встречи **в браузере**. Для приложений (Zoom, Teams, Телемост для компьютера)
  используйте десктоп-приложение Recapper.
- Звук записывается **только с одной вкладки** — той, на которой вы нажали значок Recapper и
  «Начать запись». Если встреча переехала в другую вкладку или вкладку перезагрузили,
  остановите запись, нажмите значок на новой вкладке и начните снова. Служебные страницы
  браузера (`chrome://…`) записать нельзя.
- Safari и Firefox не поддерживаются (нет нужных API: `chrome.tabCapture`, `offscreen`,
  `sidePanel`). В браузерах без боковой панели (некоторые сборки на Chromium) панель
  открывается отдельным небольшим окном.
- Ответы появляются с задержкой в длину фрагмента (по умолчанию 12 с) + время распознавания и ИИ.
- Эхо: если вы без наушников, микрофон слышит и собеседников из колонок — используйте наушники
  или отключите источник «Мой микрофон».

## Для разработчиков

```
manifest.json          MV3-манифест
background.js          service worker: значок → боковая панель, offscreen-документ, бейдж REC
sidepanel.html/.js/.css  интерфейс боковой панели
offscreen.html/.js     захват: tabCapture + микрофон → 16 кГц → WAV → POST /api/live/{sid}/audio
capture-worklet.js     AudioWorklet: блоки PCM из аудиопотока
permissions.html/.js   одноразовая выдача доступа к микрофону
lib/                   чистые модули без chrome.* (тестируются в Node):
  wav.js dsp.js chunker.js uploader.js capture-config.js api.js reducer.js md.js i18n.js
scripts/pack.mjs       сборка dist/recapper-extension-<версия>.zip
scripts/make-icons.mjs генерация иконок
test/unit/             node --test
test/e2e/              Playwright + настоящий Chromium
test/fixtures/         сервер Recapper с тестовым распознавателем, страница «встречи»
```

Тесты (Node 20+; из папки `extension/`):

```bash
node --test test/unit/*.test.mjs                    # юнит-тесты чистых модулей
xvfb-run -a node test/e2e/extension.e2e.mjs         # e2e (нужны Python-зависимости Recapper и Playwright)
node scripts/pack.mjs                               # zip в dist/
```

E2E запускает настоящий сервер Recapper (`sim-good`, распознавание заменено проверкой WAV:
16 кГц, моно, 16 бит), загружает расширение в Chromium и проходит сценарий: настройки и
проверка подключения, выбор/создание встречи, согласие, запись микрофона и звука вкладки через
offscreen-документ, задачи и ответы, «Ответить», «Спросить», быстрые действия, завершение и
ссылка на отчёт, ошибки 401/409/503, запрет микрофона. Playwright берётся из
`../desktop/node_modules/playwright` (или `PLAYWRIGHT_MODULE`), браузер — из
`PLAYWRIGHT_BROWSERS_PATH` (или `CHROMIUM_PATH`).

Нажатие на значок расширения автоматизировать нельзя, поэтому в e2e право `tabCapture` на
вкладку даёт тестовый флаг Chromium `--allowlisted-extension-id` (он снимает только проверку
«пользователь нажал значок»; остальной путь — настоящий). Проверяется вручную: нажатие значка
на реальной вкладке встречи, слышимость собеседников во время записи, сохранение разрешения
микрофона после «Разрешить».
