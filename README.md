# Recapper — ассистент встреч, который решает задачи

Recapper слушает встречу и **выполняет задачи, которые вы ставите голосом по ходу разговора**.
Скажите: «Ассистент, допиши механику монетизации игры: конверсия покупки из приложения
Самоката в Купер» — ассистент распознает команду, поднимет контекст встречи, прошлых встреч
и материалов компании, при необходимости поищет в интернете и положит готовый ответ в итог
встречи. Обычный рекап (итог, решения, поручения) он тоже делает.

## Как это работает

```
микрофон + звук собеседников ──► распознавание речи (локально, faster-whisper)
                                          │
                                          ▼
        «Ассистент, …» ──► голосовая команда ──► ответ ИИ (контекст встречи + память
                                                   прошлых встреч + база знаний + веб)
        вопросы из разговора ──► подсказки «Прозвучало на встрече» (ответ по кнопке)
        Live Assist: догнать, итог сейчас, что спросить, поручения, темы
                                          │
                                          ▼
                 итог встречи по шаблону (11 шаблонов) + ответы на ваши задачи
                 чат по встрече и по всем встречам, экспорт MD / Word / JSON
```

- **Голосовые команды** распознаются без ИИ — детерминированно, мгновенно, даже если ИИ недоступен.
  Слова-обращения настраиваются («ассистент», «рекапер», «помощник», «assistant» по умолчанию).
  Ложное срабатывание можно отменить в течение 5 секунд.
- **Подсказки** — вопросы и задачи, прозвучавшие в разговоре. Отвечаются только по кнопке
  (или автоматически, если так включено в настройках) — это экономит деньги на ИИ.
- **Память**: все встречи сохраняются локально; ответы и чат подтягивают фрагменты прошлых
  встреч со ссылками `[meeting:…]`.
- **Каждый ответ ИИ проверяется**: формат, уверенность, ссылки на несуществующие документы и
  встречи («выдуманные источники») помечаются предупреждением прямо в карточке ответа.

## Варианты (одно ядро, разные оболочки)

| Вариант | Для чего | Где |
|---|---|---|
| **Десктоп-приложение** Windows / macOS | Основной продукт: слышит Zoom, Teams, Телемост в приложениях; панель поверх окон, скрытая от показа экрана | `desktop/`, установщики — в релизах репозитория |
| **Расширение браузера** (MVP) | Встречи в браузере: Meet, Телемост, Zoom Web | `extension/` |
| **Веб / PWA** | Без установки: открыть по ссылке, установить как приложение из браузера | `python -m recapper serve` |
| **Telegram-бот** | Доставка итогов, вопросы к памяти на ходу, голосовые заметки | `python -m recapper bot` |
| **Docker** | Сервер для команды | `Dockerfile` |

Почему так, а не отдельные приложения под каждую ОС: всё, кроме захвата звука и поведения окна,
у Windows и macOS одинаково. Так же устроен Granola (Electron). Платформенные мелочи закрываются
внутри оболочки.

## Запуск на своём компьютере одной командой

**Windows** (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Saiberia/teste/claude/cloud-mode-claude-code-g6q3pn/deploy/run-windows.ps1 | iex
```

**macOS / Linux** (Терминал):

```bash
curl -fsSL https://raw.githubusercontent.com/Saiberia/teste/claude/cloud-mode-claude-code-g6q3pn/deploy/run-mac.sh | bash
```

Скрипт ставит `uv` (он сам скачает Python), Recapper с локальным распознаванием речи, создаёт постоянный токен
и открывает `http://127.0.0.1:8000/?token=…`. На Windows появляется ярлык `Recapper.cmd` на рабочем столе.
По умолчанию ИИ — OpenAI-совместимый сервер `http://127.0.0.1:8045/v1` (локальный Gemini-прокси);
в «Настройки → ИИ» можно сменить адрес, ключ и модель и нажать «Проверить подключение».

## Быстрый старт (разработка)

```bash
python -m pip install -e ".[dev,asr]"      # asr = локальное распознавание речи (faster-whisper)
export ANTHROPIC_API_KEY=...               # без ключа работает офлайн-режим (только контекст)
python -m recapper serve                   # напечатает ссылку с токеном доступа
```

Откройте ссылку `http://127.0.0.1:8000/?token=…`. Всё настраивается на экране «Настройки»
(ключ API тоже можно ввести там — он хранится локально и никогда не возвращается в интерфейс).

Другие команды:

```bash
python -m recapper process встреча.txt --kb docs/ --ask "Какой бюджет выдержим?"   # отчёт в Markdown
python -m recapper process запись.m4a --answer-all --template product --lang en
python -m recapper bot                       # нужен TELEGRAM_BOT_TOKEN и RECAPPER_TELEGRAM_ALLOWED_USERS
python -m recapper eval --provider sim-sloppy   # оценка ИИ на эталонных встречах
```

Форматы расшифровок: `Имя: реплика` (с таймкодами или без), WebVTT (Zoom, Meet, Teams, Телемост),
SRT, выгрузка Google Meet / Телемоста (имя / время / текст).

## Смена ИИ и перехват ответов

Провайдер выбирается в настройках или `RECAPPER_LLM`:

| Значение | Что это |
|---|---|
| `claude` | Claude (по умолчанию `claude-opus-5-5`, веб-поиск, серверный fallback при отказах) |
| `openai` | Любой OpenAI-совместимый сервер: OpenAI, Ollama, LM Studio, vLLM, шлюзы (`OPENAI_BASE_URL`, `OPENAI_API_KEY`, `RECAPPER_OPENAI_MODEL`) |
| `none` | Без ИИ: голосовые команды и подсказки находятся, к ним собирается контекст |
| `sim-good`, `sim-sloppy`, `sim-broken` | Симуляторы ИИ для тестов: образцовый, неаккуратный, сломанный |

**Каждый вызов ИИ перехватывается** (`TracingLLM`): что спросили, что ответила модель, время,
нарушения контракта (неверный JSON, лишние поля, нет обязательных разделов, выдуманные источники).
Смотреть — экран «Проверка ИИ» или файл `RECAPPER_TRACE=trace.jsonl`.

Прежде чем ставить другую модель, прогоните её на эталонных встречах:

```bash
RECAPPER_LLM=openai OPENAI_BASE_URL=http://localhost:11434/v1 RECAPPER_OPENAI_MODEL=qwen2.5 \
  python -m recapper eval --strict
```

Отчёт `eval-out/report.md` покажет, нашлись ли команды, есть ли лишние пункты, все ли ответы
готовы, сколько нарушений формата и были ли выдуманные источники. Сценарии — `examples/eval/*.json`.

## Настройки

Все настройки описаны в одном реестре (`recapper/prefs.py`) — из него строятся API
(`GET/PUT /api/settings`), проверка значений и экран настроек. Группы: язык (интерфейс RU/EN,
язык встречи для распознавания, язык ответов), ИИ, ассистент (слова-обращения, что отвечать
автоматически, лимит ответов, шаблон отчёта, быстрые действия), запись и распознавание,
приложение (горячая клавиша панели, панель поверх окон, скрытие от показа экрана, тема),
данные и приватность (хранить ли расшифровки, срок хранения). Переменные окружения задают
значения по умолчанию для серверных установок.

## Приватность

- Аудио не сохраняется: фрагменты распознаются и сразу удаляются. Распознавание — локально.
- Данные хранятся локально в SQLite (`~/.recapper` или `RECAPPER_DATA_DIR`); у веба и бота
  разные владельцы данных, пользователи бота не видят чужих встреч.
- Сервер всегда требует токен доступа. Telegram-бот по умолчанию закрыт: разрешите id
  пользователей (`RECAPPER_TELEGRAM_ALLOWED_USERS`) или явно `RECAPPER_TELEGRAM_PUBLIC=1`.
- Записывайте встречи только с согласия участников. В России голос — биометрия (152-ФЗ):
  для корпоративного использования нужны отдельное согласие и хранение в РФ; при подключении
  зарубежного ИИ текст встречи уходит его провайдеру — выбирайте провайдера осознанно.
- Для конфиденциальных встреч отключите веб-поиск в настройках.

## Тесты

```bash
python -m pytest -q                              # ядро, API, бот, провайдеры ИИ, настройки
node tests/e2e/web_ui.mjs <url> <token>          # браузерный сценарий интерфейса (Playwright)
cd desktop && npm test && xvfb-run -a npm run test:e2e   # десктоп
cd extension && npm test                          # расширение
```

CI (`.github/workflows/ci.yml`) гоняет тесты на Linux, Windows и macOS.
Установщики собирает `.github/workflows/release.yml` на настоящих машинах Windows и macOS
(ручной запуск или тег `v*`) и публикует их в релиз.

## Структура

```
recapper/            ядро: распознавание команд, ответы, память, рекап, Live Assist, настройки
recapper/web/        HTTP API + веб-интерфейс (он же внутри десктоп-приложения)
recapper/bot/        Telegram-бот
desktop/             Electron-оболочка для Windows и macOS
extension/           расширение браузера (MVP)
packaging/           сборка встроенного сервера (PyInstaller)
examples/            пример встречи, база знаний, эталонные сценарии для оценки ИИ
tests/               тесты (pytest) и браузерный e2e
```
